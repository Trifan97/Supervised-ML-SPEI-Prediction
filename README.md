Multi-class drought severity classification for Moldova using SPEI-3 (Standardized Precipitation-Evapotranspiration Index), built as part of the **IBM Machine Learning Professional Certificate**.

## Overview

The pipeline classifies monthly climate observations into seven drought severity classes following the WMO/McKee (1993) SPEI scheme:

| Class | SPEI-3 range |
|---|---|
| Extremely Dry | < −2.0 |
| Severely Dry | −2.0 to −1.5 |
| Moderately Dry | −1.5 to −1.0 |
| Normal | −1.0 to +1.0 |
| Moderately Wet | +1.0 to +1.5 |
| Severely Wet | +1.5 to +2.0 |
| Extremely Wet | > +2.0 |

## Dataset

`master_dataset.csv` is **synthetic** data generated by `generate_synthetic_data.py`. It reproduces the statistical properties of real Moldovan hydrometeorological records:

- 16 stations covering Moldova (1961–2020, 60 years × 12 months = 720 rows per station, 11,520 rows total)
- Realistic seasonal climatology for a continental climate
- North–south aridity gradient (southern stations warmer, drier)
- AR(1) temporal autocorrelation in precipitation and temperature
- SPEI indices computed from a synthetic water-balance series

The pipeline architecture and all ML methodology are identical to work validated on real station data.

## Key ML techniques

- **SMOTE** oversampling (30 % of Normal class) for class imbalance
- **HistGradientBoostingClassifier** with native NaN handling
- **Balanced sample weights** (`compute_sample_weight`) passed at fit-time
- **9 engineered features**: precipitation/temperature lags (6/12-month), rolling means, cumulative temperature anomaly, station lat/lon, aridity index
- **Probability calibration** via `CalibratedClassifierCV` (isotonic)
- **Ordinal-weighted F1** metric penalising cross-class errors proportional to severity distance

## Quick start

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. (Optional) Regenerate synthetic dataset
python3 generate_synthetic_data.py

# 3. Run the full pipeline — prints metrics, saves plots and .pkl artefacts
python3 modelling_pipeline_7class_v2.py
```
